**问题:** 第52行使用 `DateTime.now().timeZoneName` 返回平台特定的缩写(如"CST")而不是IANA时区名称。

**日志错误:**
```
I flutter: Failed to initialize local notifications: Location with the name "CST" doesn't exist
```

**已应用修复:**
- ✅ 添加 `flutter_native_timezone: ^2.0.0` 到 pubspec.yaml
- ✅ 更新 `local_notification_service.dart` 使用 `FlutterNativeTimezone.getLocalTimezone()` 获取正确的IANA时区名称
- ✅ 如果时区查找失败,添加UTC回退

**状态:** ✅ 代码修复已完成,等待 `flutter pub get` 和重新构建
