## P1 高优先级问题

### P1-1: 通知时区错误 ✅ 已修复

**描述:** 使用平台特定的时区缩写字符串"CST"而不是IANA时区名称

**证据:** 日志输出
```
I flutter: Failed to initialize local notifications: Location with the name "CST" doesn't exist
```

**影响:** 本地通知初始化失败,提醒功能可能不工作

**修复状态:** ✅ 代码已修复
- 添加 `flutter_native_timezone: ^2.0.0` 到 pubspec.yaml
- 更新 `local_notification_service.dart` 使用正确的IANA时区获取
- 添加UTC回退机制

**下一步:**
- [ ] 运行 `flutter pub get`
- [ ] 重新构建APK
- [ ] 在设备上验证通知功能
